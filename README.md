# Ai-MCP

Raccolta di server [MCP (Model Context Protocol)](https://modelcontextprotocol.io) che permettono ai modelli AI di operare su servizi esterni.

## Server disponibili

| Categoria | Server | Percorso | Descrizione |
|-----------|--------|----------|-------------|
| Storage | MEGA | [`Storage/Mega`](Storage/Mega) | Server PHP via HTTP con accesso a token per gestire un cloud drive [mega.io](https://mega.io): navigazione, ricerca, lettura/scrittura, upload da URL, spostamento, copia, cestino, link pubblici, condivisioni, import e quote. |

Ogni server è un progetto indipendente con il proprio `README.md`, le proprie dipendenze e le istruzioni di configurazione.
